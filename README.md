# Legendary Disco

## A disco dance party at the end of the world

**Legendary Disco** is a public playground for small toys, interactive experiments, entertainment, demos, and curious little experiences.

This is a place to play with strange things, explore bounded interactive worlds, test ideas through experience, and let useful surprises emerge.

For internal whole-ecology current routing, wall state, redirects, or drift/watch, use `UNUM-Start-Here-End-Here-Ecology-Gateway`. This README is the local public front door; no separate current-ecology companion is required.

## Current relation

Legendary Disco remains live outside the eight primary roots because public interactive toys, demos, bounded simulations, playtests, and standalone experiences have a deployment and visitor-use lifecycle that benefits from a separate public surface.

- `UNUM-Visitor` may route people here as a public exploration destination.
- `UNUM-Living-Continuum-Ecology-Systems` may own deeper shared scientific, technical, narrative, or experimental bodies from which a public toy descends.
- Kitty's Playground or other experiential surfaces may preserve lived/developmental traces of creating or playing with an experiment.
- Archives may preserve meaningful frozen states or retired public experiences.

A public demo can expose an experience without publishing all private machinery that produced it.

Working route:

```text
bounded public-safe concept / capability
-> build a standalone interactive experience
-> preserve provenance and declared omissions
-> deploy / playtest publicly
-> return technical or experiential learning to the appropriate living body
-> return ecology-level route/dependency changes to Gateway when relevant
```

## What belongs here

Legendary Disco may contain:

- playful software toys and small games;
- visual, musical, or spatial experiments;
- interactive scenes and bounded simulations;
- character or companion demonstrations;
- samples of larger capabilities that are safe to expose publicly;
- works in progress intended for playtesting and curiosity.

Each experience should stand on its own. Visitors should not need access to private repositories or unpublished theory to understand or enjoy it.

## What does not belong here

Legendary Disco is not the canonical theory archive, the complete underlying system, or a public mirror of private developmental work.

Public demos must not reconstruct, summarize, or silently expose protected core theory, private archives, participant material, stewardship keys, or unreleased canonical machinery.

A demo may show an effect without publishing every mechanism that produced it.

## Current state

The disco is open.

The first instrument is **[First Light / Last Light](toys/first-last-light/)**:
a deterministic, interactive laser-field toy that expands from a seed, dances,
folds inward, and begins again. Motion can be paused, sound is opt-in, and the
experience requires no external services or private project context.

Run it from this repository with:

```powershell
python -m http.server 8080
```

Then open:

```text
http://localhost:8080/toys/first-last-light/
```

The continuing goal remains intentionally small: build real toys one at a time
rather than filling the repository with speculative architecture.

See [PROVENANCE.md](PROVENANCE.md) for the public crossing and declared losses.
